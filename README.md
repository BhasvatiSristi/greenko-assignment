# Greenko AI Engineering Take-Home Assignment

This repository contains the completed Part A and Part B solutions plus a single Streamlit demo layer.

## Streamlit Demo

The Streamlit interface combines:

### Part A
Conversational renewable-energy operations and compliance assistant.

### Part B
Interactive 24-hour renewable generation forecasting.

Run:

```bash
streamlit run streamlit_app.py
```

## Project Structure

- Part A: `part_a/`
- Part B: `part_b/`
- EDA notebook: `notebooks/part_b_eda.ipynb`
- Forecasting notebook: `notebooks/part_b_forecasting.ipynb`
- Streamlit app: `streamlit_app.py`
